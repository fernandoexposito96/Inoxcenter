# Inoxcenter · Incidencias

Aplicación interna, móvil y sencilla para registrar y consultar incidencias de trabajo.

## Primera versión
- Acceso demo por código numérico de 5 cifras: `12345`.
- Inicio con resumen de incidencias.
- Alta de incidencia con foto, título, descripción, zona y prioridad.
- Listado y filtros por estado.
- Detalle de incidencia.
- Estadísticas e histórico mensual básicos.
- Persistencia local para el prototipo.
- Preparada como PWA base.

> Esta fase es un prototipo funcional. Antes de uso real en empresa se conectará a backend seguro para fotos, histórico compartido, roles Encargado/Jefe y permisos de edición.
